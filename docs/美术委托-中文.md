## 二、本次委托范围

**第一批只做 1 个角色**——先验证质量与沟通顺畅度，满意后再谈后续批次。

| 批次 | 内容 |
|---|---|
| **第 1 批（本次）** | **主角「旅行者」** —— 规格见第三节 |

## 三、主角规格

| 项 | 要求 |
|---|---|
| **画布尺寸** | **48 × 64 px**，每帧固定。角色本体约 40×56，**四周留 2–4 px 余白**（防止挥剑/披风被裁切） |
| **色数** | **16–32 色**（另加 1 个透明色）。超出请提前沟通 |
| **视角** | ⚠️ **必须是侧面视图**（面朝左右）。**不要正面视图**——横版游戏里正面角色无法表现朝向 |
| **像素规范** | 硬边、**无抗锯齿、无半透明渐变噪点**（像素画基本要求） |
| **描边** | 有无描边均可，但**全部动作必须统一风格** |
| **背景** | 透明（PNG alpha） |
| **角色锚点** | **脚底对齐**画布底部（我会按"脚底 = 画布底边"接入引擎） |

### 角色设计说明

| 项 | 内容 |
|---|---|
| 主题 | **元素旅人**——四元素之一：【待填：风/岩/水/火】 |
| 气质参考 | 轻装旅行者；短外套或披风（**要能看出奔跑时的动态**） |
| 配色偏好 | 【待填：例如 主色 #4A90D9 / 辅色 #FFFFFF / 点缀 #FFD166】 |
| 发型 / 服装 / 脸 | **由画师设计**（见下方"设计自由度"） |
| 设计自由度 | 【待填：**A. 完全原创**（推荐，风险最低） / **B. 我提供草图** / **C. 参考某作品气质**】 |

> ⚠️ **不要使用任何现成游戏角色的具体设计**（发型、服装、标志性配饰）。
> 需要的是"**气质与精度**"，不是"**临摹**"。

## 四、动作与帧数（核心要求）

| # | 动作 | 帧数 | 循环? | 说明 |
|---|---|---|---|---|
| 1 | **待机** | **4–6** | ✅ 循环 | 呼吸/衣摆微动 |
| 2 | **跑动** | **8–12** | ✅ 循环 | ⭐ **最关键的动作**，流畅度决定手感 |
| 3 | 起跳 | 2–3 | — | 单次 |
| 4 | 上升 | 2–3 | ✅ 循环 | 空中 |
| 5 | 下落 | 2–3 | ✅ 循环 | 空中 |
| 6 | 落地 | 2–3 | — | 单次 |
| 7 | **攻击** | **6–10** | — | 前摇 / 命中 / 收招三阶段要能看出来 |
| 8 | 冲刺 | 3–5 | — | 高速位移 |
| 9 | 受击 | 3–4 | — | 单次 |
| 10 | 死亡 | 5–8 | — | 单次 |
| | **合计** | **约 45–62 帧** | | |

**风格锚点（只作精度参考）**：

- **帧数流畅度**参考《Katana ZERO》——**这是本委托最重要的一条**，跑动/攻击的帧数宁可多、不要少
- **细节量**参考 GBA《Naruto: Ninja Council》系列
- ⚠️ 上述作品**仅用于说明精度与风格方向**，**不需要也不应该复制其任何具体设计**

## 八、验收标准

交付时我会逐条核对：

1. ✅ 尺寸精确为 **48×64**，每帧一致
2. ✅ 色数在 **16–32** 内
3. ✅ **侧面视图**（不是正面）
4. ✅ **无抗锯齿**（放大后每个像素清晰）
5. ✅ 动作的**帧序列合理**（跑动无跳帧、攻击有前摇/命中/收招）
6. ✅ **脚底对齐**画布底边
7. ✅ 提供 **Aseprite 源文件**
